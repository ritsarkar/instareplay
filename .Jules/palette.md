## 2024-05-24 - Dynamic ARIA Labels in Lists\n**Learning:** When adding accessibility to action buttons inside a `.map()` loop (like table rows or list items), a generic `aria-label="Delete"` is insufficient for screen readers because it provides no context. The user cannot distinguish which item they are deleting if they navigate by buttons.\n**Action:** Always interpolate identifying row data (e.g., `aria-label={\`Delete ${doc.title}\`}`) into the ARIA label and title attribute to ensure screen reader users have full context for their actions.
