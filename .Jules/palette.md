## 2024-07-01 - Accessible Button Focus Patterns in Next.js/Tailwind
**Learning:** Using standard `:focus` classes (like `focus:ring-2`) on buttons can cause persistent, unwanted focus rings when users click them with a mouse, degrading the visual experience. On icon-only buttons, it's easy to forget context for screen readers if `aria-label` is missing and the internal SVG isn't explicitly hidden from the accessibility tree.
**Action:** Consistently use `focus-visible:` utilities (e.g., `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-indigo-500`) instead of `focus:` to ensure focus indicators only appear during keyboard navigation. Always provide an `aria-label` and `title` to icon-only buttons, and add `aria-hidden="true"` to the inner SVG icon to prevent redundant or confusing screen reader announcements.
