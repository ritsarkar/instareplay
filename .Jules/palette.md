## 2024-06-03 - [Dynamic ARIA labels for table actions]\n**Learning:** When adding ARIA labels to repeating icon buttons in a table (like Delete), hardcoding 'Delete' is insufficient. Screen readers will just announce 'Delete, button' multiple times without context.\n**Action:** Use string interpolation with row data (e.g., `Delete ${doc.title}`) for the `aria-label` and `title` to provide precise, contextual actions for both assistive technology and mouse users.
