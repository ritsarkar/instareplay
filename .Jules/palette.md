## 2026-09-26 - Dynamic ARIA Labels for Action Buttons inside Lists and Tables
**Learning:** When dealing with action buttons inside a mapped list or table (like a 'Delete' or 'Edit' button for a specific document row), a static `aria-label` (e.g., 'Delete') is insufficient context for screen reader users because it doesn't indicate *what* is being deleted. Similarly, an `aria-label` shouldn't be added to buttons containing screen-reader-only text elements (e.g. `<span className="sr-only">...</span>`) to prevent double announcements.
**Action:** Use dynamic ARIA labels (e.g., `aria-label={"Delete " + doc.title}`) to inject identifying information from the surrounding scope into the `aria-label` and `title` attributes. Ensure icon-only buttons include `type="button"`, apply `aria-hidden="true"` to the internal icon, and avoid adding `aria-label` if the button already employs an SR-only span.
